# Amazfit Packages

Gói cài đặt (đã build) cho các ứng dụng và mặt đồng hồ Zepp OS. Repo công khai để mã QR hoạt động lâu dài; mã nguồn nằm ở repo riêng tư.

Cách cài: mở app Zepp > Hồ sơ > chọn đồng hồ > Chế độ nhà phát triển > dấu + > Quét, rồi quét mã QR đúng với mẫu đồng hồ.
